# 校园消费记账

CS3331 HW1 的桌面 GUI 作业，使用 Python 自带的 Tkinter 和 SQLite。界面可以记录生活费支出，按本月统计总额和各类别金额，达到预算时显示提醒。

## 启动

安装带 Tkinter 的 Python 3.10 或更新版本，在本目录运行：

```console
python app.py
```

消费日期填写 `YYYY-MM-DD`，金额单位为元。填写日期、金额和类别后点击“添加记录”；选中一行后点击“删除选中记录”。在“每月预算”旁填写金额并保存，可以看到本月剩余额度或预算提醒。

记录和预算保存在本目录的 `data/ledger.sqlite3`，每次操作都会保存，重新打开程序后会继续读取。第一次启动会自动创建数据文件。可用 `python app.py --db 文件路径` 指定另一份账本。

## 检查

```console
python -m unittest -v
```

测试使用临时数据库，检查录入、按月统计、删除和重新读取数据。不会写入日常使用的账本。
