# 校园消费记账

CS3331 HW1 的桌面 GUI 作业，使用 Python 自带的 Tkinter 和 SQLite。界面可以记录生活费支出，按所选月份统计总额和各类别金额，达到预算时显示提醒。

## 启动

安装带 Tkinter 的 Python 3.10 或更新版本，在本目录运行：

```console
python app.py
```

消费日期填写 `YYYY-MM-DD`，月份和日期均需写满两位，金额单位为元。填写日期、金额和类别后点击“添加记录”。选中一行后点击“删除选中记录”，核对确认窗口中的日期、金额和类别，再决定删除或取消。在“每月预算”旁填写金额并保存，可以看到本月剩余额度或预算提醒。

“查看月份”默认是当前月份，输入 `YYYY-MM` 并点“查看”可以查其他月份。消费列表、统计和提醒均对应所选月份；添加其他月份的消费后，当前查看月份保持不变，切换到对应月份即可看到新记录。每月预算金额是统一设置，适用于所有月份。

记录和预算保存在本目录的 `data/ledger.sqlite3`，每次操作都会保存，重新打开程序后会继续读取。第一次启动会自动创建数据文件。可用 `python app.py --db 文件路径` 指定另一份账本。

## 检查

```console
python -m unittest -v
```

测试使用临时数据库，检查录入、按月统计、删除和重新读取数据。不会写入日常使用的账本。

运行 `python gui_check.py` 可以启动真实窗口并自动调用按钮，检查错误输入和取消删除等操作。检查中弹窗的回答由测试程序提供。
